# Starter

Look at the [DiscordJS documentation](https://discord.js.org/docs/packages/discord.js/14.22.1).

## Setup

Make sure to install the dependencies:

```bash
# npm
pnpm install
```

## Development Server


Start the development server on:

```bash
# npm
pnpm run dev
```

## Production

Deploy commands when building for production:

Modify deploy-commands.ts.exemple to deploy-commands.ts set token, clientid and guildid. 

```bash
# npm
pnpm run deploy
```

Build the application when building for production:

```bash
# pnpm
pnpm run build
```
